## Problem Statement

The Covid-19 India Dashboard provides a **state-level analysis** of the pandemic’s spread, testing, vaccination progress, and demographic breakdown within India.  
It enables healthcare leaders, policymakers, and researchers to track **confirmed cases, deaths, recoveries, and vaccination coverage** over time.

Key questions addressed include:

* Which Indian states reported the highest Covid-19 cases and deaths?
* How do testing and positivity rates vary by state?
* What role did vaccinations play in reducing case severity?
* Which age groups and genders were most affected?

---

## Steps Followed

* **Step 1** : Covid-19 India dataset was loaded into Tableau Public, cleaned, and pre-processed.  
* **Step 2** : Created calculated fields for **fatality rate, recovery percentage, and vaccination coverage**.  
* **Step 3** : Developed interactive filters for **State/UT, Case Type, Date Range**.  
* **Step 4** : Built key KPI cards and visuals for:
  * Confirmed Cases  
  * Deaths  
  * Recoveries  
  * Vaccination Doses (by type and count)  
* **Step 5** : Added charts for:
  * Map → **Total deaths by state** (Maharashtra showing ~24M deaths, lowest ~3.9K in some states)  
  * Line Chart → **Covid case trends (confirmed, cured, deaths)** over time  
  * Bar Chart → **Testing details** per state (e.g., Uttar Pradesh ~11.38B tests, Andhra Pradesh ~4.96B tests)  
  * Donut Charts → **Age group distribution** (20–29 yrs: 24.86%, 30–39 yrs: 21.10%, 40–49 yrs: 16.18%)  
  * Vaccination Breakdown → CoviShield (61.9B), Covaxin (7.96B), Sputnik V (28.9M)  
  * Dose Progress → 1st Dose (56.5B), 2nd Dose (13.5B)  
  * Gender Split → 66.76% Male, 33.24% Female  
* **Step 6** : Used Tableau formatting, highlight actions, and tooltips for interactivity.  
* **Step 7** : Published dashboard to **Tableau Public**.

## Insights

### [1] State-Level Impact
* **Maharashtra** recorded the highest death toll (~24M).  
* States like **Uttar Pradesh** and **Andhra Pradesh** conducted the highest number of Covid-19 tests (~11.3B and ~4.9B respectively).  
* Smaller states/UTs recorded much fewer cases and deaths.  

### [2] Demographic Breakdown
* **20–29 age group** was most affected (24.86%), followed by **30–39 yrs (21.10%)** and **40–49 yrs (16.18%)**.  
* Gender distribution shows a **higher male impact** (66.76%) compared to females (33.24%).  

### [3] Vaccination Insights
* **CoviShield** was the most widely used vaccine (~61.9B doses).  
* **Covaxin** (~7.96B) and **Sputnik V** (~28.9M) had smaller shares.  
* **First dose coverage** (~56.5B) far exceeded **second dose coverage** (~13.5B).  

### [4] Testing Analysis
* **Uttar Pradesh** led in testing with **11.38B samples**, followed by **Maharashtra** (~7.3B) and **Bihar** (~7.39B).  
* Testing coverage highlights **regional differences** in detection and containment strategies.

## Conclusion

The Covid-19 India Dashboard provides an **interactive and data-driven lens** to assess the pandemic’s impact at the national and state level.  

By using this dashboard, policymakers and health experts can:  

* Identify states with **high mortality and positivity rates**.  
* Understand **age and gender vulnerabilities**.  
* Track the **effectiveness of vaccination campaigns**.  
* Plan resource allocation (tests, vaccines, medical facilities) more effectively.  

This tool acts as a **decision-support system for public health management** during the Covid-19 crisis.
